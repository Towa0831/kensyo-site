# お知らせ記事の型

news の手順書から読む。依頼に合う型を選び、「おすすめの見せ方」で記事の形を提案し、「記入用の一覧」で必要な情報を聞く。
一覧の★は必須。Issueや `site.yml` から分かる項目は、先に埋めて返す。

型を増やしたいとき（管理者向け）：同じ形で、このファイルの末尾に追記する。

---

## 1. 展示会・イベントへの出展（例: エコプロ、産業フェア、地域のお祭りへの出店）

- 種類（category）：イベント
- おすすめの見せ方
  1. 冒頭の1〜2文：「〇〇に出展します」＋会期
  2. 開催概要の表：展示会名／会期／開場時間／会場／ブース（小間）番号／入場料・事前登録
  3. `## 出展内容`：展示・紹介するものを箇条書き（3〜5個）
  4. 来場登録や公式サイトへのボタン（URLがあれば）
  5. 来場の呼びかけと、問い合わせ先
- 画像：出展物やブースの写真があれば写真。なければ「ブースで来場者を迎える様子」などのイラスト
- 公開のタイミング：会期の2〜4週間前がおすすめ
- 合わせて出すとよい記事：会期後の出展報告（型 5）
- 気をつけること
  - 展示会のロゴやマークは使わない（イラストにも描かない）
  - 会期・会場・入場料は、担当者が書いたものだけを使う。あなたの知識で埋めない
  - 掲載終了日は付けない（会期後も活動の記録として残す）のが基本。担当者が希望したときだけ付ける

記入用の一覧（「エコプロの出展を告知したい」と頼まれたときの例）：

```
@claude
★展示会の正式な名前：エコプロ（「エコプロ2026」など、正式な名前を書いてください）
★会期（日付）：
　開場時間：
★会場：
★ブース（小間）番号：
★出展する内容（箇条書きでOK）：
・
・
　来場者へのひとこと：
　入場料・事前登録：無料／事前登録が必要／分からない
　公式サイトや来場登録のURL：
　問い合わせ先：ホームページの連絡先（000-000-0000）でよい／ほかの連絡先：
★公開日：すぐ ／ 〇月〇日
★画像：イラストをおまかせ ／ 写真を貼る ／ なし
```

## 2. 自社のイベント・説明会・セミナー

- 種類：イベント（採用説明会は「採用」）
- おすすめの見せ方：冒頭で「〇月〇日に〇〇を開きます」→ 開催概要の表（日時／場所／定員／参加費／対象）→ `## 内容`（プログラムを箇条書き）→ `## お申し込み方法`（ボタンまたは連絡先）→ 締め切り
- 画像：会場や前回の様子の写真。なければ内容に合うイラスト
- 公開のタイミング：開催の3〜4週間前
- 掲載終了日：申し込みの締め切りがあれば、開催日の翌日をすすめる
- 記入用の一覧の★：イベント名／日時／場所／内容／参加費／申し込み方法（電話・メール・フォームのURL）／公開日／画像。あれば：定員、対象、締め切り、持ち物、駐車場

## 3. 休業・営業時間の変更（年末年始、夏季休業、臨時休業など）

- 種類：休業案内
- おすすめの見せ方：冒頭で「〇月〇日〜〇月〇日は休業します」→ 期間の表（休業期間／営業再開日）→ 休業中の問い合わせの扱い → お詫びのひとこと
- 画像：なし（をすすめる）
- 公開のタイミング：休業の2〜4週間前。臨時休業はすぐ
- 掲載終了日：営業再開日の翌日をすすめる
- 記入用の一覧の★：休業の期間（最初の日と最後の日）／営業再開日／休業の理由（年末年始、設備点検など）／公開日。あれば：休業中の問い合わせの扱い（メールは受け付ける、など）、緊急連絡先
- すでに同じ時期の休業案内があれば、新しく作らずに、その記事を直すかを確認する

## 4. 新しいサービス・取り組みの開始

- 種類：お知らせ
- おすすめの見せ方：冒頭で「〇月〇日から〇〇を始めます」→ `## 〇〇とは`（2〜3文）→ `## 特長` または `## ご利用いただける方`（箇条書き）→ 料金や開始日の表 → 問い合わせ・申し込み
- 画像：サービスの様子の写真。なければ内容を表すイラスト
- 記入用の一覧の★：サービス・取り組みの名前／始まる日／内容（誰の、どんな困りごとを解決するか）／公開日／画像。あれば：料金、対象地域、申し込み方法、関連ページのURL

## 5. 活動報告（地域活動、出展報告、表彰・受賞、社内行事）

- 種類：お知らせ
- おすすめの見せ方：冒頭で「〇月〇日、〇〇を行いました／に参加しました」→ 概要の表（日時／場所／参加者／成果）→ `## 当日の様子`（2〜4文、写真があれば本文の途中にも）→ 参加した社員の声（あれば）→ 今後に向けたひとこと
- 画像：当日の写真をすすめる（貼ってもらう）。なければイラスト
- 公開のタイミング：活動の1週間以内
- 記入用の一覧の★：何の活動か／日付／場所／内容・成果（数字があれば）／公開日／画像。あれば：参加人数、社員の声、お礼を伝えたい相手

## 6. メディア掲載（新聞、テレビ、雑誌、Webメディア）

- 種類：メディア掲載
- おすすめの見せ方：冒頭で「〇〇（媒体名）で当社の〇〇が紹介されました」→ 掲載情報の表（媒体名／掲載日・放送日／内容）→ 記事へのリンク（あれば普通のリンク）→ お礼のひとこと
- 画像：なし をすすめる（記事の画面や紙面は、媒体の許可がないと載せられないため）
- 記入用の一覧の★：媒体名／掲載日・放送日／紹介された内容／公開日。あれば：記事のURL、番組名・コーナー名

## 7. 採用に関するお知らせ（募集開始、採用説明会）

- 種類：採用
- おすすめの見せ方：冒頭で「〇〇の募集を始めました」→ 募集している職種の箇条書き → 採用情報ページへのボタン `[採用情報を見る](jobs/index.html){: .button }`
- 求人の中身（給与・勤務時間など）はお知らせに書かず、求人ページを作る（`.claude/skills/job/SKILL.md`）。求人ページがまだなければ、先に求人を作るかを確認する
- 記入用の一覧の★：募集する職種／募集を始める日／公開日。あれば：応募の締め切り、説明会の日時

## 8. 大事なお知らせ（料金の改定、移転、電話番号の変更、サービスの終了、お詫び）

- 種類：お知らせ
- おすすめの見せ方：冒頭で結論（何が・いつから変わるか）→ 変更前 → 変更後 の表 → 理由（1〜2文）→ お客様へのお願いや対応 → 問い合わせ先
- 画像：なし をすすめる
- 公開のタイミング：変更の1か月以上前をすすめる（お詫びはすぐ）
- 記入用の一覧の★：何が変わるか／変更前と変更後／いつから／公開日。あれば：理由、お客様にしてほしいこと
- 電話番号や住所の変更は、`site.yml` の連絡先や会社概要も合わせて直す必要があるかを確認する（直すときは edit の手順書）

## 時期ごとのネタ（漠然とした依頼のとき）

今日の日付から1〜2か月先までの時期を見て提案する。すでに同じ内容の記事があれば提案しない。

| 時期 | ネタの例 |
| --- | --- |
| 1月 | 新年のあいさつと今年の取り組み、年始の営業開始 |
| 2〜3月 | 年度末の営業日のご案内、春の採用情報、1年間の活動のまとめ |
| 4月 | 新年度のごあいさつ、新しい仲間の紹介、ゴールデンウィークの休業案内（4月中旬まで） |
| 5〜6月 | 地域活動の報告、夏の採用、サービスの紹介 |
| 7〜8月 | 夏季休業の案内（7月中）、暑さ・熱中症への取り組み |
| 9月 | 防災への取り組み（防災の日）、秋のイベントの告知 |
| 10〜11月 | 展示会・イベントの出展予告、地域活動の報告、年末年始休業の案内（11月中） |
| 12月 | 年末年始休業の案内（まだなら）、1年のお礼、出展報告 |
| いつでも | 新しいサービス・取り組み、メディア掲載、受賞、社員の声、よくある質問への回答 |
